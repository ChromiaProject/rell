UNRELEASED NOTES

1. Tools: New code actions convert a function or query body between block and expression form

The language server now offers the refactoring pair "Convert to expression body" and "Convert to block
body" (LSP code actions of kind refactor.rewrite) for the function or query under the cursor, mirroring
the Kotlin intentions of the same names:

    function f(x: integer): integer {
        return x + 1;
    }

converts to

    function f(x: integer): integer = x + 1;

and back.

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
2. Tools: Attributes declared by a bare type name are highlighted as attributes

An attribute declared by a name with implicit type, such as `name` in

    entity user { name; }
    object greeting { mutable name = "World"; }

used to get the semantic token of a type reference, so editors coloured it like a type. The
language server now emits an attribute token for such declarations in entity, object and struct
bodies, matching attributes declared with an explicit name (`name: text`).
